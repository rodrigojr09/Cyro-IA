# JARVIS 4.1.0

Publicação e compilação autorizadas pelo proprietário em 22/10/2026. Origem Cloud: `https://cronosjarvis.vercel.app`; repositório privado `rodrigojr09/Jarvis`, branch `master`.

## Alterações

- Chats gerais e Quick Chat geral no PostgreSQL Cloud, isolados pela conta de login.
- Uma conversa Quick fixa por conta, sem criar outra a cada sessão. Quick Chat de projeto usa histórico local fixo por projeto.
- Projetos, arquivos, chats de projeto, notas e permissões continuam locais. Histórico local anterior não é enviado automaticamente.
- Projetos de uso geral: estudos, escrita, planejamento, pesquisa e software, inclusive com notas e sem arquivos selecionados.
- Até 5 MB (5.242.880 bytes) de arquivos selecionados no total. Desktop avisa antes de salvar/enviar; backend local recalcula e rejeita excesso com HTTP 413, inclusive no streaming e após crescimento de arquivos.
- A migration aditiva `20261022120000_cloud_chats` foi aplicada ao banco configurado antes desta publicação, sem reset de dados.

## Validação

O pipeline `tools/build_cloud_desktop.py` executa testes Cloud, TypeScript, build Next.js, testes Python/Node, quatro verificações Electron, PyInstaller, NSIS e auditoria das fontes dentro do ASAR. O teste `tools/smoke_cloud_release.py` verifica o payload gerado com diretório temporário e PATH restrito, bloqueio de histórico sem login e persistência local após reinício.

Não há chamada paga de IA/áudio nessa validação. Testes com provedores simulados não comprovam áudio pago; execução em máquina de desenvolvimento não certifica Windows limpo. O instalador não possui certificado de assinatura configurado.

Saída esperada: `release/v4/JARVIS-Setup-4.1.0.exe`, acompanhada de checksum SHA-256. Não criar tag de release antes da conclusão dos testes.
