# Cyro Desktop 8.7.0-rc.1 — IDE dos EVs

IDE interna no EV: edição e download de arquivos de texto, tabelas JSON com
prévia, solicitações de execução e saída persistida no espaço. SDK 0.1.2 expõe
workbench.list/writeFile/createTable/remove/requestExecution com permissão
workbench. O chat propõe as alterações e respeita confirmação e revisões.

Execução local opcional requer Docker Desktop e imagens locais preparadas pelo
usuário. Não executa no processo da API ou no shell Windows. Cada execução exige
aprovação nativa do código/snapshot; sem rede e sem pastas pessoais, com usuário
não root, raiz somente leitura, limites de memória/processos/tempo/saída. Arquivos
criados pelo processo no contêiner são temporários; arquivos salvos pelo SDK são
persistidos no EV. Docker ausente nesta máquina: execução real não certificada.

Validação concluída: 180 testes Desktop, 223 Python, 31 de inicialização/build,
quatro de plataforma e oito cenários Electron aprovados. SDK: sete testes; API:
160 testes e build; portal: três testes e build. QA visual da IDE em Chromium.
Teste focado posterior conferiu o timeout interno/remoção do contêiner e o editor.

Instalador gerado e auditado, com self-check do executável e smoke do payload
real aprovados: inicialização, autenticação local e persistência após reinício,
sem Node/Python no PATH e sem API paga. Nenhum perfil pessoal usado.

Para usar: abra um EV e clique no ícone de código no cabeçalho. Arquivos e tabelas
funcionam sem Docker. Para executar, instale/inicie Docker Desktop em modo Linux
e prepare somente as imagens desejadas:

```sh
docker pull python:3.12-alpine
docker pull node:24-alpine
docker pull alpine:3.21
```

Esses comandos de preparação não foram executados automaticamente.
