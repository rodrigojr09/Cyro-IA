# 7.0.0-alpha.0 — plataforma independente

- Desktop preservado no repositório original, com API pública padrão https://api.cyro-ia.tech e recursos locais existentes.
- Backend e Cloud independentes, contratos sincronizados e painel em https://admin.cyro-ia.tech.
- Atualizador usa API e Cyro Files; valida tamanho, hash, formato e versão antes da instalação. Falhas temporárias permitem nova tentativa.
- Credenciais GitHub administradas pelo painel e criptografadas exclusivamente no Backend; nenhuma criação automática de tags.
- Ferramentas opcionais em tools/platform organizam os quatro checkouts e executam validação isolada sem ler configurações de produção.
- Preparação de deploy e rollback em docs/v7/PRODUCTION.md. Nenhum deploy, migration ou release real executado.
- Alpha: homologação na VPS, serviços reais e instalação Windows permanecem necessárias. Históricos locais existentes são preservados; não há migração automática deles para o servidor.
