# Cyro Desktop 10.0.0

- Configurações → Catálogo de EVs permite buscar, inspecionar, instalar e
  desinstalar EVs. Os detalhes exibem avisos de versão do SDK.
- O Cyro Logístico 1.1.0 e o SDK 0.1.7 foram integrados ao Backend. Os comandos
  `/fretes` e `/fretes tabela` usam NF-e processadas anexadas à mensagem.
- O Backend pode servir o binário oficial de releases públicas pela rota
  compatível com o atualizador instalado. A rota conserva autorização e
  continua atendendo releases privadas pelos caminhos existentes.
- O Backend orienta o chat a apresentar resultados e pendências em linguagem
  direta. Orientações internas ficam separadas dos dados usados como referência.

## Janela principal em Next.js

O build web fica em `web/` no repositório do Desktop. O instalador recompilado
carrega `https://web.cyro-ia.tech/` após o login e usa a interface empacotada se
o site estiver indisponível. Login e Chat rápido rodam em janelas locais.

`f54a53f8aad55030787113a5b394042367920e1826b755d9bc10390ccd65c2bd`.
Sem assinatura Authenticode. O build Next.js foi validado em Electron por
HTTP local, com sessão e operações de EV em ambiente sintético.
