# Cyro 9.0.0

EVs continuam sendo chats privados, com memória própria e uso autorizado da memória principal.
A pasta abre o explorador de arquivos, tabelas e execuções. Código abre no painel lateral,
com destaque de sintaxe, numeração, rascunhos protegidos e salvamento com revisão.
Trechos de código do chat podem abrir no editor ou preparar execução após clique.

O preview lateral apresenta saída de execução, texto, Markdown, JSON e HTML estático
sanitizado, sem scripts ou acesso à rede. Executar Python, JavaScript ou shell exige
Docker instalado e confirmação nativa; o SDK nunca inicia comandos silenciosamente.
Docker não está disponível na máquina de desenvolvimento: execução real em contêiner
permanece dependência externa, coberta aqui por testes do executor e das permissões.

Tabelas criadas pelo chat/SDK abrem na lateral para edição. Tabelas existentes mantêm
tipos e precisão decimal; paginação evita carregar todas as linhas. CSV neutraliza
fórmulas e exporta a página visível das tabelas centrais. Arquivos anexados podem virar
cópias editáveis; o original permanece preservado. Conflitos de revisão conservam o rascunho.

SDK 0.1.4 adiciona ctx.panels, executeFile e os eventos onFileSave, onTableSave e
onExecutionResult. API permanece versão 1 e pacotes anteriores continuam compatíveis.
Publicação e atualização automática dos EVs preservam chats, memória, arquivos e estado.

Validação: 190 testes JavaScript, 223 Python, 31 de empacotamento, 4 de plataforma e oito cenários Electron reais passaram. API: 166 casos cobertos, com o caso de persistência revalidado após atualizar a expectativa do prompt; build e integração HTTP de produção com banco/contas sintéticos aprovados. Portal: três testes, build e layout desktop/mobile. SDK: nove testes e igualdade dos bytes entre fonte, pacote, API e portal.
Capturas reais Electron em build/v9. Instalador em release/v9/Cyro-IA-Setup-9.0.0.exe,
preservando os instaladores anteriores. Sem tag ou release automática.
