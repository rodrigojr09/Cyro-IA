# Cyro 8.5.0-rc.1 — 18/11/2026

Cada EV é um chat privado criado pelo menu Novo EV, abaixo do Quick Chat.
O usuário escolhe nome e tipo instalado pelo catálogo da conta. O modelo
Logístico é uma extensão independente; SDK com onInstall, onUninstall, onCreate,
onUpload, onMessage e onSave, além de load/save/send/files. Guia para novos EVs
em cyro-ev-sdk/README.md e cyro-backend/docs/ev/EXTENSIONS.md no workspace.
Memória privada usa também a MAIN da mesma conta; arquivos continuam privados.
Notas e arquivos abrem pelo ícone de pasta no canto do cabeçalho.

O proprietário autorizou remover as instâncias antigas: a migration arquiva e
marca os EVs Logísticos legados como excluídos, sem apagar fisicamente arquivos
ou histórico e sem importar os dados para novas instâncias. Migra-se somente o
modelo ao catálogo. Pacotes executam código confiável no servidor; não há sandbox
Node nem upload arbitrário de código pelo usuário.
