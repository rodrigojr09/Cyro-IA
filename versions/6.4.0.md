# 6.4.0 — projetos independentes

Separação estrutural compatível a partir da 6.3.1. O Git original continua Desktop; Backend e Cloud estão em pastas irmãs com manifestos, locks, versões, testes, builds e documentação próprios.

- Desktop deixa de usar workspaces Cloud/shared; preserva Electron, IPC, runtime Python local, caminhos JARVIS, login e atualizador. A origem da API central continua em JARVIS_CLOUD_ORIGIN.
- Backend recebe os 17 handlers originais, autenticação, regras administrativas, Prisma, IA, Spotify e versões. Adiciona sessão administrativa de consulta, health/readiness, Redis, integração com SDK oficial Files e tabela aditiva FileBinding.
- Cloud recebe apresentação Next.js e transporte HTTP restrito, sem persistência ou segredos de serviços. Layout e contrato de cookies preservados; autorização continua no Backend.
- Migrations originais preservadas byte a byte. Nenhuma migration ou alteração de dados de produção executada.
- A alteração preexistente em cloud/next-env.d.ts foi preservada localmente; o arquivo saiu do índice junto com a extração e não é usado pelo Desktop.
- Ambientes locais ignorados do antigo Cloud permanecem no lugar, sem leitura ou migração de segredos.

Resultados finais, commits e limitações constam no relatório de separação. Sem publicação de repositórios, push, tags, releases ou deploy. Instaladores anteriores preservados; Setup 6.4.0 gerado e auditado com a origem HTTPS anterior como ponte. Troca para o novo Backend depende de deploy e origem homologados.
